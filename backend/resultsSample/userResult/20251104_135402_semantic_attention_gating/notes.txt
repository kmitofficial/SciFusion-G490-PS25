# Title: Semantic Gating for Enhanced Nuance in Transformer Self-Attention
# Experiment description: Modify the `BertClassifier` class to intercept the intermediate representations within the self-attention modules of the BERT layers. Implement a small, learnable 'similarity module' that takes token embeddings and outputs a similarity score for each query-key pair. This score will be used to gate the computed attention weights before the softmax operation. The training and evaluation pipeline will remain largely the same, allowing comparison of performance with and without this semantic gating.
